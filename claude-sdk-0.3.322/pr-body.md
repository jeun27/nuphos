## Summary

Bumps the Claude Agent SDK pinned in the runtime image from 0.3.319 to 0.3.322, using the repo's own `apps/runtime/scripts/update-claude-sdk.mjs`:

- `apps/runtime/image/Dockerfile`: `ARG CLAUDE_AGENT_SDK_VERSION=0.3.322`
- `apps/runtime/image/claude-agent-acp/package.json`: `overrides["@anthropic-ai/claude-agent-sdk"]`
- `apps/runtime/image/claude-agent-acp/package-lock.json`: regenerated by `npm install --package-lock-only`. The diff only moves `@anthropic-ai/claude-agent-sdk` and its eight platform packages to 0.3.322. No new packages.
- `apps/runtime/README.md`: the version in the image table

`apps/runtime/package.json` is not bumped, so merging does not release a runtime.

## Why

Claude Code 2.1.321 added Claude Fable 5.2 (`claude-fable-5-2`) as the default Fable model. Desktop has no model list of its own. The picker shows what the runtime reports. With 0.3.319 the runtime still reports **Fable 5.1** for the `fable` alias, so Fable 5.2 can't be picked in Nuphos.

Model options the adapter reports (`node test/model-discovery.mjs claude-code`, no prompt sent):

| id | 0.3.319 | 0.3.322 |
| --- | --- | --- |
| `opus` | Opus 5.5 | Opus 5.5 |
| `fable` | **Fable 5.1** · $10/$50 per Mtok | **Fable 5.2** · $8/$40 per Mtok |
| `sonnet` | Sonnet 5.5 | Sonnet 5.5 |
| `haiku` | Haiku 5.5 | Haiku 5.5 |
